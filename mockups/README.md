# Siteline UI mockups

Three static HTML directions for a calmer Siteline UI. Open `index.html` in a browser to compare them, or open any mockup directly.

| File | Direction | Fonts | Palette |
|---|---|---|---|
| `a-clear-desk.html` | Inbox-first, sidebar plus site drawer | Plus Jakarta Sans, JetBrains Mono | Warm paper, teal, action orange |
| `b-sunday-morning.html` | Overview bento | Fredoka, Nunito | Cream, tangerine, trust blue |
| `c-night-shift.html` | Site-first, one page per site | Bricolage Grotesque, DM Sans | Warm dark, Siteline yellow |

Every mockup covers the same three things: inbound documents, open sites, and where each agreement's data lives (mailbox, Daytona sandbox, Claude extraction, Postgres, S3).

Fonts load from Google Fonts. Everything else is inline, so the files need no build step. All site, person and file names are fictional.
